# Org Bar (Dateien + Einstellungen in the top bar) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the duplicated "where am I" text in the top bar with the org logo plus always-reachable Dateien and Einstellungen buttons, and remove both from the sidebar.

**Architecture:** `AppShell` gets an optional `bar` slot that replaces `<PageTitle>` in the top bar (admin keeps `PageTitle`). A new client component `OrgBar` renders logo + the two links with active state. The sub-pages that used to be sidebar children (10 settings sections, 2 file pages) move into a new `SectionNav` inside their own layouts.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind v4, shadcn sidebar/tooltip, `src/i18n` messages (de + en).

**Spec:** the user's request in this session (no spec file). Read `AGENTS.md` › Design system / One style guide before touching UI.

## Global Constraints

- No hardcoded UI text: reuse `files.title`, `shell.settings`; any new key goes in `de.json` and `en.json`.
- Semantic Tailwind classes only (no raw colours); icons from `lucide-react` (`FolderIcon`, `SettingsIcon`, as in the old sidebar).
- Icon-only buttons need `<Tooltip>` + `aria-label`; touch targets ≥ `size-8`.
- Works at 375 / 768 / 1280 px, light + dark. Top bar stays `h-12`.
- Files link only with `ctx.can("org.files.view")` (as before).
- `npm run lint` and `npm run build` must pass. No AI attribution in commits.

## Review Focus

- User without `org.files.view`: no Dateien button, Einstellungen still there.
- Org without logo / very long org name: `Picture` initials fallback, name truncates, bar never overflows at 360 px.
- Phone width: buttons collapse to icon-only, sidebar trigger still visible, Sprout button still fits.
- Sidebar collapsed to icons and Sprout panel open (bar gets narrower): no wrap or overlap.
- Non-managers on `/settings/*`: `SectionNav` shows only tabs they may see (`SETTINGS_TABS` permission filter).
- `/admin` unchanged (still `PageTitle`, no org bar).
- Deep links `/settings/<key>` and `/files/templates` still work and highlight the right item.
